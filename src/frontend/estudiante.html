Primera instalación

Configura un ESP32 nuevo

Instala el firmware por USB antes de registrar y vincular el dispositivo al proyecto.

Descargar firmware.bin Abrir instalador web
  1. Conecta el ESP32 al computador con un cable USB de datos.
  2. Descarga el archivo firmware.bin desde este panel.
  3. Abre esptool-js, selecciona el puerto COM y el archivo descargado.
  4. Instala el firmware. Si lo solicita, mantén presionado BOOT y pulsa EN/RESET.
  5. Reinicia la placa y vuelve aquí para buscarla y vincularla.
La primera instalación siempre requiere conexión USB. Las actualizaciones posteriores pueden hacerse por WiFi.
